🎯 Objetivos de facturación

Objetivo calculado para cerrar el faltante de cash flow ($40.435.000), repartido proporcionalmente entre web y local sobre la base de agosto 2026.

Se compara contra el mismo Nº de días inmediatamente anterior. Local: solo suma semanas cuyo lunes caiga dentro del rango — es aproximado.
📐 Por categoría — solo prenda real (web)

Filtrado a categorías de producto reales, ignorando etiquetas de promo/colección (Winter Sale, Liquidación, etc.). Útil para planificar cuánto cortar de cada categoría.

¿Falta o sobra alguna categoría en la lista? Avisame para ajustar el filtro.

🗓️ ¿Qué fecha estás cargando?

Elegí exactamente la fecha que quieras — no se ajusta sola a ningún lunes. Usalo como identificador de esa carga (por ejemplo, el último día del período que exportaste de Ninox). Podés volver para atrás y cargar fechas pasadas una por una.

📄 Subir Excel de Ninox

🔥 Cyber

Sugerencia automática: productos con más de 45 días en la web y lentos (200+ días de stock, sin ventas, curva rota, o invierno desde 90 días), web + local. Cada uno va a la promo de precio fijo más baja que le conviene por costo, o a la de % OFF. Lee el precio promocional de Tienda Nube y calcula el % sobre lo que se cobra hoy. Podés asignar cualquier producto (sugerido o no) a la promo que quieras, editar el precio cyber de cada uno, cargar el costo real y crear, editar o desactivar promos en ⚙ Promos. Todo queda guardado.
